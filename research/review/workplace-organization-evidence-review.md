- 来源：47篇来自优先材料；`208《好战之徒》`经原文回查批准为唯一补录。
- 核心字段：`claim / evidenceNature / boundary / ordinal / quote` 缺失0。

## 双模型审查与主线程裁决

两路审查都同意八层结构成立，也都反对按相关度分数直接截取前六。第一路更强调流程、纪律、劳动定价和制度接口；第二路逐篇回查后更强调直接职场命题、证据性质和适用边界。最终清单采用第二路的48篇逐字核验结果，并吸收第一路对 `208《好战之徒》`漏召回的确认。

旧06号论文八篇材料中，`2《后半句》`、`17《做事第一》`、`50《一人之上》`、`60《工德无量》`、`117《圆滑2》`进入核心。`20《有所成》`讨论家庭帮助与成事正当性，`61《正衣冠》`主要讨论服饰和职业主体符号，均降为外围。`30《清静无为》`主要重建庄子的低欲路线，只作为转述性对照，不能直接冒充岐伯本人的职场方案。

`208《好战之徒》`没有通过标题、问题窄词或正文六词阈值，但正文直接讨论劳动、工作和学习的过程快感。其漏召回来自词面阈值，不是语义无关，因此显式登记为 `direct-review-supplement`，并由构建脚本要求补录数只能为1、ordinal只能为208。

## 四条跨文主线

1. **劳动快感—事业投入—职业资本。** `208/60/1624`从过程快感、志业投入和客户反馈说明劳动动力，`962/2132`再把动力压到关键交付、战绩和作品。
2. **选择—交付—证词—再选择。** `312/1625/3874/649`处理职业适配与路线，`625/876/1804`把路线转成可交付专业服务，`494/2772`再用相邻证词和真实市场反馈校正下一步。
3. **授权—困难上报—担责—组织记忆。** `3665/2946`限定服从与正式命令，`3183/419`把风险报告和督导写入责任链，`788/868/1231`使危机、会议、功劳和失败进入可追溯制度。
4. **使命—体谅—合作—裁判。** `117/2750/1419`规定体谅与社会化的合作条件，`470/1656/2`让差异成员围绕交付协作并分功，`1997/1268/729`再用规则、裁判和预审处理无法只靠关系解决的问题。

这些路径是研究者对材料的重建，不是岐伯自称的“四条组织原则”。

## 二十组内部张力

1. 劳动过程本身可成为快乐 / 工作所得又被要求继续投入事业：`208 / 60`。
2. 志业型人生把健康和家庭视为基础投入 / 关键交付之后仍须承担家庭事务：`60 / 962`。
3. 倦怠要靠重新进入服务正循环 / 琐碎善后仍应通过流程减少：`1624 / 1581`。
4. 具体职业会中断 / 战绩和作品可以延长职业生命：`2132`一文两端。
5. 职业适配要看是否愿意过成功者的生活 / 重大选择无法保证正确：`312 / 1625`。
6. 专家路线要求换公司不换专业 / 领袖路线可能换岗位不换组织：`649`一文两端。
7. 低于市场公允价可以辞职测试 / 已达公允价后苦劳不能自动换来加薪：`938`一文两端。
8. 产出优先于无限名誉辩解 / 交付物仍须说明期限、定义和资源：`17 / 625`。
9. 客户追加修改应追加合同和价格 / 初入行者仍须先靠作品与投入取得议价资格：`876`一文两端。
10. 非营利组织不以利润为本位指标 / 专业服务和组织盈余仍不可被压低：`1281`一文两端。
11. 开源可以免费 / 开源事业仍须让维护者与生态获得可货币化收益：`1804`一文两端。
12. 个人必须把工作做好 / 成果必须承认流程和同事贡献：`17 / 2`。

14. 团队成员可以不认同战略 / 仍应按专业标准履行职责：`470`一文两端。
15. 服从是主动选择 / 违法、超授权或不可执行命令不产生同样义务：`3665 / 2946、1268`。

## 可见文本中的历时配对

- `3874《职业规划》(2019)` → `2132《职业生命》(2023)` → `50《一人之上》(2026)`：从元职业，到战绩作品，再到AI条件下的业务与所有权。
- `3665《服从领导》(2020)` → `3183《有困难就说》(2021)` → `788《平乱》(2025)`：从授权内服从，到风险上报，再到组织危机中的高层担责。
- `2946《不服从管理》(2021)` → `868《面向纪要会议》(2025)` → `625《工作重点》(2025)`：从命令留痕，到会议纪要，再到交付式汇报。
- `3482《智能失业》(2021)` → `2772《裁员过渡》(2022)` → `50《一人之上》(2026)`：从未来制度设想，到个体市场反馈，再到AI创业适应。
- `2《后半句》、17《做事第一》、60《工德无量》均集中于2026年`：晚期文本内部同时存在产出、分功和强志业，不能据此断言单向思想转型。

这些只能称为可见表达重点和问题场景的变化。平台迁移、提问类型和篇幅变化都可能改变主题可见度，不能据此断言作者完成了线性转向。

## 高分误召回与召回缺口

- `1249《政策观察》`：66分，主旨是就业政策阅读及落实机制，不承担职场组织主干。
- `3926《5G》`：63分，大量企业、办公和技术词造成高分，主旨仍是通信基础设施与产业推演。
- `3680《批评》`、`3801《财富观》`、`3277《服从》`、`4025《芯片》`：分别属于一般批评、财富总论、亲子教育和产业史。
- `3894《世界史》`、`3797《反犹》`、`2844《零起点》`：因组织、能力、规则和责任词进入多类，实际分别以文明、族群史和亲子秩序为主。
- 除核心补录 `208《好战之徒》` 外，`61《正衣冠》`、`62《人上人上人》`、`73《摊牌忍者》`、`20《有所成》`也是语义相关而词面不足的外围材料，但不足以挤占直接职场核心席位。

## 最可能的过度综合

1. 把八层或四条跨文主线写成作者自称的组织理论。
2. 把志业型人生写成所有雇员的无条件加班义务。
3. 把客户、供应商、市场价格和利润语言扩展到所有公共部门、家庭及非营利组织。
4. 把分功写成平均分配；`2《后半句》`只要求承认真实贡献和流程条件。
5. 把圆滑写成讨好，或把所有策略性体谅都写成真诚。
6. 把培训、普通上下级、师徒培养和终身共同体混成同一种关系。
7. 把管理服务论、纪律服从论与竞争裁判论无缝合并，抹掉它们之间的权力张力。
8. 把薪酬、纪律、合规和劳动定价判断写成外部法律结论。
9. 把AI、自动化和未来分配制度写成已经实现或必然发生的事实。
10. 把晚期程序性文章增多直接解释为岐伯从宏观理论转向微观技巧。

最终论文应保留旧稿“产出—分功—体谅”的发现，但将其放回劳动目的、职业形成、正式权柄、组织政治、制度竞争、离职失业和未来工作组成的更大结构中。
