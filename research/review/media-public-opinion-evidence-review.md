# 媒体舆论专题原文复核记录

## 复核范围

本轮复核对象为 `research/papers/29_媒体舆论与公共认知秩序.md`、`research/data/media_public_opinion_core_evidence.csv` 及其32篇原始正文。复核不判断岐伯关于新闻、平台、心理、司法、资本和国际政治的外部事实是否正确，只检查论文是否准确归属作者判断，是否把单篇事件外推成通则，以及八组张力是否由原文两端支持。

机械层已经另行通过：32个核心ID唯一，八层各4篇，题名、日期、URL和连续短引失败0；论文使用32个核心ID，无表外ID。此次复核只处理命题支持和跨文综合。

## 核心证据结论

32篇核心证据均能支持其所在小节的主命题，没有发现作者立场被反向改写、题名或事件对象错配、转述被误作作者赞同等高风险错误。论文对下列强事实主张均保留了文本归属和外部未核验边界：

- 《谣谣乐》中的企业经营判断；
- 《无可妥协》中的袭击动机和限流效果；
- 《为什么我们会输掉认知战》中的组织成本和具体宣传主体；
- 《沉默的大多数》中的多数心理与案件态度；
- 《舆论战》《反犹》中的大国心理、宗教史和国际传播因果；
- 《新奥义》中的资本结构、产品竞争和媒体影响；
- 《镜中的小丑》《嘲笑鸟》中的记忆、成瘾和注意力机制。

## 八组张力复核

1. **媒体互相揭错 / 表达者绕过采访：成立为角色条件差异。** 《怎样读新闻》讨论读者怎样使用已存在的媒体材料，《不受采访》讨论已有直接渠道者是否交出语境控制。两篇没有互相否定。

2. **开放言路 / 评论区删评：成立。** 《带节奏》限制公共环境用口袋罪取消异议，《控评责任》《删评权》把作者评论区与平台独立发表空间分开。平台自身删帖、推荐和封禁仍未展开。

3. **核验责任 / 认知战成本劣势：成立。** 《无根消息》《谣谣乐》处理日常信息卫生，《为什么我们会输掉认知战》处理有组织攻击。原文支持核验必要，却不支持把逐条辟谣写成赢得认知战的充分策略。

4. **公共信息传播 / 限制有害行为流量：成立。** 《规范求助》的信息越准确越有助于协调行动，《无可妥协》则认为某类袭击报道会成为行为奖励。适用差异来自作者判断的传播后果。

5. **治理平台输入 / 平台窗口不是时代：成立为时间尺度差异。** 《信源管理》讨论人在既有平台中如何筛选信源，《落后时代》否定错过单个平台窗口等于退出历史。二者是互补条件，不是严格矛盾。

6. **公共影响力 / 个人互动空间：成立，但原标题补入外部要求。** 《持公器》要求公众借出的影响力不得用于私人报复，《删评权》支持作者管理评论区。原论文所说“私人裁量怎样接受公共监督”不是原文命题，现已改成“两种权柄怎样分界”。

7. **反代言原则 / 多数心理强判断：成立。** 《沉默的大多数》既反对把沉默者自动登记为己方，又直接断言多数通常站在法律和秩序一边。论文已把后者限定为作者模型，不当成调查事实。

8. **服务目标受众 / 拒绝特定关系：成立，但原标题证据不足。** 《一万粉》《柳下会》支持有效信息、利他分享和长期关系，却没有明示“听取关系反馈”；《公什么关》支持不修复所有负面关系。现已改成原文能支持的“面向所欲服务者创造价值 / 拒绝特定关系”。

## 体系综合复核

“来源—剪裁—放大—判断—行动—反馈”六环是研究者跨文重建，不是岐伯自称的传播理论。32篇证据能分别支持六环中的主要问题，但不支持把它写成严格单向因果或封闭流程。论文已经明确说明这是综合结构，并保留以下未完成处：

- 有根消息不保证正确；
- 媒体博弈没有解决共同盲点；
- 核验不能自动消除组织成本不对称；
- 声量不能代替多数调查；
- 作者评论区裁量不能直接推出平台治理规则；
- 内容价值不能保证增长；
- 拒绝公关不能证明对方必然恶意。

复核后，六环仍可保留为导航模型。它的证据性质应始终标为跨文重建，不能用来替作者补出完整媒体制度。

## 复核结果

- 核心证据进入正文：32/32；
- 作者立场反向改写：0；
- 具体事件无边界外推：0；
- 需要修订的过度综合：2；
- 已完成修订：2；
- 机械短引和元数据状态：`PASS`。

本轮复核提高了媒体论文的命题支持度，但它不替代未来由另一模型重新从原始正文出发的盲审；后者仍应重点检查非核心候选中是否存在足以改变八层结构的强反例。
